# Constitution — Humanoid Robot Directory

프로젝트의 변하지 않는 원칙. 모든 spec/plan/구현은 이 문서를 따른다.

## 프로젝트 정체성

전 세계 휴머노이드 로봇 정보를 웹에서 수집·정규화하여, 검색 가능한 카탈로그로 보여주는 사이트.

- **목표**: "최대한 많은" 휴머노이드 로봇을 한곳에서 검색·비교
- **데이터 출처**: 제조사/위키/뉴스 사이트 웹 스크래핑 + AI 검색(LLM/검색 API) 병행

## 기술 스택

- **프레임워크**: Next.js (App Router) + TypeScript
- **스타일링**: Tailwind CSS v4
- **패키지 매니저**: pnpm
- **테스트**: vitest
- **린트**: ESLint (eslint-config-next)

## 코딩 컨벤션

- 코드 주석은 한국어로 작성
- 커밋 메시지는 영어로 작성
- 컴포넌트는 서버 컴포넌트 우선, 상호작용이 필요할 때만 `"use client"`
- import alias `@/*` 사용

## 비기능 요구사항

- **SEO**: 로봇 상세 페이지는 SSR/메타데이터 제공 (검색 노출이 핵심 가치)
- **데이터 정규화**: 출처가 달라도 동일한 `Robot` 스키마로 통합
- **출처 표기**: 모든 로봇 데이터는 출처 URL과 수집 시각을 보관
- **점진적 수집**: 수동 시드 → 스크래핑 → AI 검색 순으로 데이터 보강 가능해야 함

## 제약 조건

- 외부 사이트 스크래핑은 robots.txt와 이용약관을 존중하고, 요청 rate limit을 둔다
- AI 검색 결과는 출처가 불확실하므로 "검증되지 않음" 표시 후 사람이 승인
